# Copilot Instructions for Hugo Resume Site

## Overview
This is a Hugo static site using the PaperMod theme. The main feature is a **Markdown-based resume** that can be rendered as a webpage and printed to PDF.

## Resume System

### Main Resume File
- **Location**: `content/resume/index.md`
- **Layout**: Uses custom template at `layouts/resume/single.html`
- **CSS**: Styled by `static/css/resume.css` with print-specific rules

### How It Works
1. Write resume content in Markdown (`index.md`)
2. Hugo renders it as HTML using the custom layout
3. CSS styles it to look like a traditional resume
4. Print media queries ensure it prints cleanly as a one-page PDF
5. The page includes a "Save to PDF" button that triggers `window.print()`

### HTML in Markdown
The Hugo config (`hugo.toml`) has `markup.goldmark.renderer.unsafe = true` to allow raw HTML tags in Markdown. This enables formatting like:
```markdown
### **Company Name** <span class="right">Job Title · Dates</span>
```

### CSS Classes
- `.right` - Right-aligns content (used for job titles/dates via flexbox)
- `.normal` - Removes bold styling for inline text
- `.no-print` - Hides elements when printing (e.g., the PDF button)

## Modular Resume Pieces (Shortcodes)

### Purpose
Swap resume sections (projects, skills, jobs) for different job applications without copy-pasting.

### Shortcode Location
`layouts/shortcodes/resume-piece.html`

### How It Works
```html
{{- $piece := .Get 0 -}}
{{- $path := printf "content/resume/_pieces/%s.md" $piece -}}
{{- readFile $path | markdownify -}}
```

The shortcode reads a Markdown file from `_pieces/` and injects its content.

### Pieces Directory
Store reusable resume sections in:
```
content/resume/_pieces/
  project-crossword.md
  project-climate-portal.md
  skills-backend.md
  skills-robotics.md
```

### Usage in Resume
```markdown
## **Autonomous Star Tracking Gimbal** · <span class="normal">Personal Project (2024)</span>
- Built offline-capable triple-axis gimbal...

{{< resume-piece "project-crossword" >}}

# Education
```

### Creating a New Piece
1. Create a new `.md` file in `content/resume/_pieces/`
2. Write the section content (no front matter needed)
3. Use the same formatting as the main resume (headers, spans, etc.)
4. Reference it with `{{< resume-piece "filename-without-extension" >}}`

### Example: Swapping Projects for Different Roles
**For a robotics job:**
```markdown
{{< resume-piece "project-gimbal" >}}
{{< resume-piece "project-robotics" >}}
```

**For a backend job:**
```markdown
{{< resume-piece "project-crossword" >}}
{{< resume-piece "project-climate-portal" >}}
```

## Key Files Reference

| File | Purpose |
|------|---------|
| `content/resume/index.md` | Main resume content |
| `content/resume/_pieces/*.md` | Modular resume sections |
| `layouts/resume/single.html` | Resume page template |
| `layouts/shortcodes/resume-piece.html` | Shortcode for injecting pieces |
| `static/css/resume.css` | Resume styling (screen + print) |
| `hugo.toml` | Hugo config (has `unsafe = true` for HTML) |

## Running Locally
```bash
hugo server
# Resume at http://localhost:1313/blog/resume/
```

## Printing to PDF
1. Open resume in browser
2. Click "Save to PDF" button (or Ctrl/Cmd+P)
3. Save as PDF - CSS print rules ensure proper formatting
